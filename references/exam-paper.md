# 错题复盘卷 spec 规范

组卷前必读。spec.json 是 `scripts/build_exam.py` 的唯一输入，字段不对脚本会直接报错。

## 整体结构

```json
{
  "title": "错题复盘卷",
  "subtitle": "Notion 错题库 · 闭卷复盘",
  "scope": "408 操作系统 · 错误次数≥2 · 共 12 题",
  "date": "2026-09-19",
  "duration_hint": "建议 30 分钟",
  "sections": [ ... ]
}
```

- `title` / `subtitle`：报头标题，缺省有默认值。
- `scope`：本次选题范围说明，会印在报头上，例：「操作系统 · 进程管理 · 错题优先」。
- `date`：默认今天，`YYYY-MM-DD`。
- `duration_hint`：建议时长，例：「建议 30 分钟」；可空。
- `sections`：题型分组数组。**必须按 single → multi → judge → blank → subjective 排序**（单选→多选→判断→填空→简答），脚本在每个科目桶内也会强制按此顺序重排，spec 里乱序无效。原因：subjective 大题答题卡区 CSS 带 `page-break-before: always`，若大题排最前，科目标题后第一页几乎全空；客观题必须在前填满首页。
- **section 名称编号按科目各自从「一」开始**：数学部分如「一、单项选择题（数学）」「二、填空题（数学）」「三、解答题（数学）」；408 部分重新编号「一、单项选择题（408）」「二、填空题（408）」。数学和 408 的 section 分开写（不要把两科的单选混在同一个 section）。

## sections 内每道题的公共字段

所有题型都有：

```json
{
  "stem": "题干文本",
  "answer": "...",
  "analysis": "解析文本",
  "source": "可选，来源",
  "tags": ["可选标签"],
  "qid": "可选，错题编号如 CT-41，印在题号旁",
  "subject": "高等数学 或 408（必填，决定分到哪一卷）"
}
```

- `stem` 必填；纯文本，支持换行（`\n`），不要写 HTML 标签。
- `answer` 必填；格式随题型（见下）。
- `analysis` 可空；**答案卷不显示解析**，此字段可不填或留空字符串。
- `source` / `tags` 可空；答案页每题右下角小字显示。
- `qid` 可空；印在题号右侧灰色等宽小字，方便做完回 Notion 定位原题。
- **`subject` 必填，且只有两个合法值**：`"高等数学"` 或 `"408"`。脚本按此字段分桶，**线性代数的题也必须填 `"高等数学"`**（math 桶 = 高数 + 线代），填成 `"线性代数"` 会产生第三个桶并被排到 408 之后。408 四门（数据结构/计组/操作系统/计网）统一填 `"408"`。

## 各题型字段

### single（单选题）

```json
{
  "type": "single",
  "name": "一、单项选择题",
  "questions": [
    {
      "stem": "下列关于进程的说法，正确的是？",
      "options": {"A": "选项一", "B": "选项二", "C": "选项三", "D": "选项四"},
      "answer": "B",
      "analysis": "解析内容……",
      "source": "2023 年 408 真题",
      "tags": ["进程管理"]
    }
  ]
}
```

- `options` 必填，键为 A/B/C/D…（按字母序），值为选项文本。
- `answer` 是单个大写字母，必须是 options 的键之一。

### multi（多选题）

```json
{
  "type": "multi",
  "name": "二、多项选择题",
  "questions": [
    {
      "stem": "以下属于进程调度算法的有（  ）",
      "options": {"A": "FCFS", "B": "LRU", "C": "RR", "D": "SPF"},
      "answer": "ACD",
      "analysis": "B 是页面置换算法……"
    }
  ]
}
```

- 字段同 single；`answer` 是多个大写字母拼接（如 `"ACD"`），脚本会校验字母都在 options 里且不重复。
- 题目名建议带"多选"提示，避免用户当单选做。

### judge（判断题）

```json
{
  "type": "judge",
  "name": "三、判断题",
  "questions": [
    {
      "stem": "线程是 CPU 调度的最小单位。（  ）",
      "answer": true,
      "analysis": "进程是资源分配最小单位，线程是调度最小单位。"
    }
  ]
}
```

- 不需要 `options`。
- `answer` 是 JSON 布尔 `true` / `false`。
- 题干末尾建议自带 `（  ）` 答题位；没有模板也会在答案区给出。

### blank（填空题）

```json
{
  "type": "blank",
  "name": "四、填空题",
  "questions": [
    {
      "stem": "操作系统通过____实现进程间的同步与互斥。",
      "answer": "信号量（PV 操作）",
      "analysis": "信号量是经典同步机制……"
    }
  ]
}
```

- `stem` 中用 `____`（连续 3 个以上下划线）表示空；模板会把下划线渲染成答题横线。
- 一道题允许多个空，但 `answer` 字段仍为单个字符串——多空时答案用 `；` 分隔，顺序和题干中空的顺序一致。
- `answer` 是文本。

### subjective（简答/论述题）

```json
{
  "type": "subjective",
  "name": "五、简答题",
  "questions": [
    {
      "stem": "简述进程与线程的区别。",
      "answer": "①资源分配：进程是资源单位，线程共享进程资源；②调度：线程是调度单位；③开销：线程切换更快；④通信：线程可直接读写进程内存，进程需 IPC。",
      "analysis": "答题要点……"
    }
  ]
}
```

- 不需要 `options`。
- `answer` 填最终结果（计算题）或参考要点（论述题）。
- **大题答题卡式排版**：题干全宽横向排列（每题之间正常间距），下方答题框**两栏并排、纯白底深色边框、高度直达页底**，每页固定 2 道大题（`build_subjective_twocol()`）。整个大题 section 强制另起一页。

## 校验规则（脚本强制）

- 总题数 ≥1，**不设上限**：所有到期/逾期题全部入卷，有多少出多少，页数随题量自然增长。
- 每个 section 至少 1 题；每个科目桶内 section 强制按 single → multi → judge → blank → subjective 排序。
- 每题 `stem` 非空、`answer` 非空。
- single/multi：`options` 非空，`answer` 的每个字母都在 options 键里。
- judge：`answer` 必须是布尔值。
- blank：`stem` 必须含至少一个 `____`。
- subjective：`answer` 作为参考要点，不做空值校验。
- `source` / `tags` 可空；`tags` 是字符串数组。

## 排版约束（模板已固定，不要改结构）

- A4、12mm 页边距，正文 11pt。
- **只产出 2 个 PDF**：`exam-YYYYMMDD-questions.pdf`（题目卷）和 `exam-YYYYMMDD-answers.pdf`（答案卷），不输出 HTML。
- **科目顺序固定**：题目卷里高等数学（含线代）在前、408 在后，科目之间 `page-break-before: always` 自动分页，绝不混在同一页；答案卷顺序相同。
- **每个科目内部题型顺序固定**：单选 →（多选）→（判断）→ 填空 → 简答；客观题自然流动排版，简答题为答题卡式两栏答题框（每页 2 题，整段另起页）。
- **题量不设上下限**：到期题全部入卷，不截断；某科 0 题则该科整段不出现。
- **答案区**：独立 PDF，标题「… · 答案」，逐题：题号 + qid（灰色小字）+ 答案（红色加粗）。**不显示题干、不显示解析**。analysis 字段可留空。
- 题目区**绝不**出现 answer/analysis；这是闭卷卷，泄题即作废。
- 单选题选项竖排（A、B、C、D 各一行），不长的选项也可以横排——由脚本按选项长度自动选。
- 多选题题号后自动加「（多选）」小标签。
- 判断题题号后自动加「（  ）」答题位。

## 常见坑

1. **把解析写进了题干**：抽题时 Notion 里题干列可能混着答案（如"正确答案是 B"），必须剥掉，否则题目页就泄题了。发现这种情况，把答案从 stem 里抠到 `answer`，原 stem 改写成纯问题。
2. **选项里带换行**：选项文本里的 `\n` 要替换成空格或 `<br>`，脚本会处理，但不要塞 HTML 标签。
3. **答案字母小写**：统一转大写。
4. **同题多空但 answer 没分号**：填空多空时答案必须按空的顺序用 `；` 连接，否则用户对不上。
5. **题太多导致答案区跨页**：正常，脚本不限制答案区页数；只校验答案区一定新起一页。
6. **超长题干**：题干 >500 字时在题对象上加 `"long": true`，模板自动用 10pt 渲染并收紧行距。

## 生成命令

```bash
python3 <本技能目录>/scripts/build_exam.py spec.json \
  --outdir <输出目录> \
  --name exam-20260919
```

stdout 会打印 JSON：`html` / `pdf` 路径、`pages` 总页数、各题型题数。`pages` < 2 说明题目区只有半页（凑 5 题以上一般不会）；答案区一定新起一页由 CSS 保证。
